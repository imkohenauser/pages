# Web Naming Conventions

Name the domain concept, role, or result. Use consistent vocabulary and omit redundant context.

1. Follow explicit project rules, then local usage, then repository-wide usage. Use [conventions.md](references/conventions.md) for gaps.
2. Recommend one name. Include alternatives only when they express different meanings.
3. For a rename, update consumers using [rename-safety.md](references/rename-safety.md) and run relevant checks.
4. For a review, report the current name and location, the problem, the recommended name, and any compatibility impact.

Keep changes within the requested scope. Preserve published names unless the task includes their migration.
